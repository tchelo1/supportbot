A technical support chatbot built in Python with SQLite persistence.
Designed to simulate real customer service interactions, identify common user issues, and perform smart automated responses.

🧠 Features

🗣️ Natural message interpretation and simple command handling

💳 Recognition of common support issues, such as:

Card machine not working

Declined transactions

Blocked account

Duplicate charges

Missing receipt

🧮 Automatic math calculations (e.g., “10 divided by 2”, “7 plus 5”)

💾 Logging of all interactions in an SQLite database (support.db)

📡 Runs 100% offline in the terminal

🧩 Modular structure, ideal for learning and further expansion

🚀 How to Run

Requirements: Python 3.x installed

# Clone the repository
git clone https://github.com/your-username/supportbot.git  

# Enter the folder
cd supportbot  

# Run the bot
python supportbot.py
